# Bug register

The **only** bug register (ADR 0185 D3): one row per bug; **status is a
column, not a section** (edit `Status`, never cut/paste the row — the
open→closed rotation this replaces was chronically skipped). The **Doc**
column links to [docs/bugs/archive.md](archive.md) for the **48** ids below
that have a heading of their own there (anchor computed from the heading
text); **2** more have a per-bug `docs/bugs/<ID>.md`. The other **111** carry
no Doc link because no body is reachable by anchor: a measured **10**,
checked against the archive's full text, have no trace of any kind; most of
the rest do have detail somewhere in the archive — a bare table row or an
inline write-up folded under a different heading — but nothing of their own
to link to. ⛔ The old "**~152** archived bodies" figure (ADR 0185) counted
every archived write-up, headed or not, including the pre-2026-07
`P<phase>-NNN` rows that predate the `BUG-<CODE>` id scheme entirely and
cannot match a row here; corrected here per ADR 0186.

**Status:** `open` · `fixed` · `verified` · `wontfix` · `duplicate` ·
`untriaged`. **Severity** (D4 — what the bug blocks), + `unrated` where the
source gives no severity signal (never invent one):

| Level | Emoji | Definition |
|---|---|---|
| `catastrophic` | ⛔ | PHI exposure, a cross-tenant read, or data loss |
| `critical` | 🔴 | blocks the pilot, or returns a wrong authz answer |
| `high` | 🟠 | blocks a phase gate |
| `medium` | 🟡 | wrong behaviour with a workaround |
| `low` | 🟢 | cosmetic or documentation |
**Per-bug doc:** `docs/bugs/<ID>.md` ([template](README.md)) once severity is
`high`+, root cause needed investigation, or it reopened — no row reads
`fixed`/`verified` while its doc's `Root cause`/`Regression protection` is
empty. **New ids:** `BUG-<CODE>-<short-slug>` — slugs don't collide like
sequential numbers do.
